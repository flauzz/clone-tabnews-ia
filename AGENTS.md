# Contexto do Projeto para Agentes de IA (AGENTS.md)

Este documento serve como guia e referência de contexto operacional para agentes de IA que atuam neste repositório.

---

## 🎯 Visão Geral do Projeto
* **Nome do Projeto:** `clone-tabnews-ia`
* **Objetivo:** Implementação do [TabNews](https://tabnews.com.br) no contexto do [curso.dev](https://curso.dev), utilizando o auxílio de agentes de inteligência artificial.

---

## 🛠️ Stack Tecnológica
* **Linguagem / Runtime:** JavaScript / Node.js
* **Framework:** Next.js (App Router)
* **UI:** React
* **Gerenciador de Dependências:** `npm`

---

## 🚀 Comandos Principais
* `npm run dev`: Inicia o servidor local de desenvolvimento.
* `npm run build`: Compila a aplicação para produção.
* `npm run start`: Inicia o servidor em modo de produção.

---

## 🧭 Diretrizes Gerais para Agentes
* Seguir as convenções e padrões idiomáticos do Next.js (App Router) e React.
* Manter consistência estilística e arquitetural em novos componentes, rotas e módulos.
* Validar alterações executando os scripts adequados (`npm run dev` / `npm run build`) sempre que pertinente.
